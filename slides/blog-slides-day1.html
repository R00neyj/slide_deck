claude
Supabase 의 my-blog 프로젝트에 글을 저장할
posts 테이블을 만들어줘. 다른 프로젝트는 건드리지 말 것.

- public 스키마, 열은 아래와 같게
  - id: bigint, generated always as identity, 기본키
  - title, content: text, not null
  - author: text, not null, 기본값 '익명'
  - created_at: timestamptz, not null, 기본값 now()
- 샘플 글 2개 (author 는 '운영자')
  - '첫 번째 글' / '데이터베이스에서 가져온 첫 글입니다.'
  - '두 번째 글' / '새로고침해도 사라지지 않습니다.'
- RLS 를 켤 것
- anon 에게 select 권한만 주고 누구나 읽는 select
  정책을 만들 것. insert, update, delete 는 금지
- 실행 전에 SQL 전체를 먼저 보여주고, 내가 허락하면 실행

  .VITE_SUPABASE_PUBLISHABLE_KEY

  createClient(url, key)
