my-blog 안에 sns_posts 표 추가

claude
Supabase 의 my-blog 프로젝트에 SNS 게시물을 저장할 sns_posts 테이블을
만들어줘. 기존 posts 테이블과 다른 프로젝트는 건드리지 말 것.

- public 스키마에 sns_posts. 열은 samplePosts.ts 의 Post 타입과 같은 이름
  - id: bigint, 자동 번호(generated always as identity), 기본키
  - author: text, 비어 있으면 안 됨
  - content: text, 비어 있으면 안 됨
  - images: text[] (사진 주소 목록), 비어 있으면 안 됨
  - created_at: timestamptz, 비어 있으면 안 됨, 기본값 now()
- 게시물 50개. 내용은 요구사항.md 주제에 맞추고 사진은 picsum 주소로 1~4장씩
- created_at 은 지금부터 1시간 간격으로 과거로 흩어 둘 것
- RLS 를 켤 것
- anon 역할에게 sns_posts 의 select 권한만 주고, 누구나 읽을 수 있는
  select 정책을 만들 것. insert, update, delete 는 허용하지 말 것
- 실행하기 전에 쓸 SQL 전체를 먼저 보여주고, 내가 허락하면 실행할 것
- 끝나면 만든 테이블, 정책, 넣은 게시물 개수를 알려줘
idauthorimages
1빵순이{…/a/600, …/b/600}
2밀가루{…/c/600}
………
50산책러{…, …, …}

images: text[]

글자 목록을 칸 하나에 담는 형식. 사진마다 표를 따로 두면 둘을 이어 붙이는 개념이 하나 더 생김
