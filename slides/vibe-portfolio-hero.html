4-1🖱 내가 직접

휴대폰 폭으로 보기

브라우저에서 F12 → 기기 모드(휴대폰 아이콘)를 켜고 확인. 이상한 건 본 것을 그대로 말하거나 용어로 바꿔 고침

✓히어로 버튼이 화면 안에 들어오는가
✓칩(또는 탭)이 화면 밖으로 넘치지 않는가
✓모달 내용이 화면 안에 다 들어오는가
✓엄지로 누르기에 버튼이 너무 작지 않은가터치 영역
4-2💬🖱 둘 다

1주차 방식 그대로 배포

1주차에 고른 방법할 일
방법 A (GitHub Actions)git push 후 저장소 Actions 탭에서 초록 체크 확인
방법 B (gh-pages 브랜치)npm run deploy 후 git push로 소스코드도 올림
안 되면이렇게 함
예전 화면이 그대로Ctrl + Shift + R
Actions가 빨간 X대부분 타입 오류로 빌드 실패. 로그를 복사해 "빌드가 실패했어. any 쓰지 말고 고쳐줘"
여기까지 하면내아이디.github.io/my-portfolio/에서 히어로와 걸러 보기·모달이 보임
정리

오늘 네 가지

  1. 디자인은 내 레퍼런스 메모에서 나옴. 교안 예시를 그대로 쓰면 다 같은 결과가 나옴
  2. 지시는 무엇을 / 어디에 / 하지 말 것만 짧게. 빠진 건 화면을 눌러 보고 찾아서 고침
  3. 같은 카드를 거르면 칩, 내용 전체를 바꾸면 탭
  4. 용어가 안 떠오르면 AI에게 용어 후보를 먼저 묻고 내가 고름
