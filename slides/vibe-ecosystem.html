description: Summarizes uncommitted changes
  and flags anything risky. Use when the
  user asks what changed, wants a commit
  message, or asks to review their diff.
---

## Instructions

Summarize the changes in two or three
bullet points, then list any risks
you notice.

3-2스킬의 정체

평소엔 목차만 들고 있음

* 단계적 공개(progressive disclosure) : 목차만 들고 있다가 필요한 장만 펴 보는 방식

4장

MCP · 바깥 서비스로 이어진 전화선

명령 한 줄로 연결하고, /mcp 로 확인

4-1왜 필요한가

브라우저 탭 안은 못 봄

MCP 없이

  • Claude가 만지는 곳 : 내 컴퓨터의 파일과 터미널
  • Notion·Figma·Supabase 내용은 내가 복사해서 붙여 넣음

MCP 연결 후

Claude Code
Notion · GitHub · DB
  • Claude가 그 서비스를 직접 읽고 조작함

* MCP(Model Context Protocol) : AI 도구와 바깥 서비스를 잇는 공개 표준 규격. 서비스 쪽에 MCP 서버를 하나 만들어 두면 여러 AI 도구가 같은 방식으로 붙음

4-1왜 필요한가

이런 요청이 가능해짐

이슈 트래커 + GitHub
JIRA 이슈 ENG-4521에 적힌 기능을 추가하고 GitHub에 PR을 만들어줘
Slack + Figma
Slack에 올라온 새 Figma 디자인으로 이메일 템플릿을 고쳐줘
데이터베이스
PostgreSQL에서 이 기능을 쓴 사용자 10명의 이메일을 찾아줘

출처: Claude Code Docs · MCP (code.claude.com/docs/ko/mcp) 예시를 줄여 옮김

4-2🖱 터미널에서

연결은 한 줄 명령

종류서버가 사는 곳명령 형태
원격 (HTTP)인터넷 주소claude mcp add --transport http <이름> <주소>
로컬 (stdio*)내 컴퓨터에서 실행claude mcp add <이름> -- <실행 명령>
원격 예 · Notion
claude mcp add --transport http notion https://mcp.notion.com/mcp
로컬 예 · 공식 문서 형태
claude mcp add example --env API_KEY=your-key -- npx -y @example/mcp-server
⚠️
-- 앞은 Claude Code의 옵션, 뒤는 서버를 띄우는 명령. 빼먹으면 옵션이 섞여 실패함

* stdio : 내 컴퓨터에서 서버 프로그램을 띄워 놓고 표준 입출력으로 주고받는 방식

출처: Claude Code Docs · MCP (code.claude.com/docs/ko/mcp)

4-3🖱 내가 직접

연결 확인과 로그인

Claude Code 안에서
/mcp
  • 연결된 서버 목록과 상태가 나옴
  • 로그인이 필요한 서버(Notion 등)는 여기서 골라 브라우저로 인증
터미널에서
claude mcp list
claude mcp get notion
claude mcp remove notion
list전체 목록
get서버 하나 자세히
remove삭제
4-4어디에 저장되나

저장 범위 세 가지

범위쓸 수 있는 곳저장 위치팀과 공유
local (기본값)지금 프로젝트에서 나만~/.claude.json안 함
project이 저장소의 모든 사람프로젝트 루트 .mcp.json커밋하면 공유
user내 모든 프로젝트~/.claude.json안 함
범위 바꾸기
claude mcp add --scope user --transport http notion https://mcp.notion.com/mcp

아무것도 안 붙이면 local 임

출처: Claude Code Docs · MCP (code.claude.com/docs/ko/mcp)

증상의심할 것해결

🛡️
믿을 수 있는 서버만 연결. MCP 서버는 내 계정 권한으로 바깥 서비스를 만짐. 바깥 글을 읽는 서버는 그 글에 숨은 가짜 지시(프롬프트 주입*)에 노출될 수 있음
🔎
서버 찾기 : Anthropic Directory (claude.ai/directory) 의 원격 서버는 claude mcp add 로 붙일 수 있음

* 프롬프트 주입 : 웹페이지나 문서 안에 AI에게 내리는 가짜 지시를 숨겨 두는 공격

실무 활용 팁

써 보면서 챙길 것

  • 같은 부탁을 세 번 했으면 스킬로 만들 신호. "방금 한 작업을 스킬로 만들어줘"라고 시켜도 됨
  • description에는 내가 실제로 쓰는 말("커밋 메시지 써줘", "배포해줘")을 넣음
  • 되돌리기 어려운 일을 하는 스킬은 disable-model-invocation: true 로 내가 부를 때만 돌게 함
  • MCP 서버와 플러그인은 쓰는 것만 켜 둠. 안 쓰는 것도 책상 자리를 조금씩 차지함
  • 팀 저장소라면 스킬은 .claude/skills/, MCP는 .mcp.json 에 두고 커밋. API 키는 커밋하지 않음
심화 — 지금은 몰라도 됨

나중에 찾아볼 것

context: forkfrontmatter에 넣으면 스킬이 서브에이전트처럼 따로 떨어진 책상에서 돎
스킬 → 플러그인스킬 폴더에 .claude-plugin/plugin.json 을 추가하면 플러그인으로 묶임
Agent Skills 공개 규격같은 SKILL.md 를 다른 AI 도구도 읽음. Claude Code 전용 필드는 무시될 수 있음
