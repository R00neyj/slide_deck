실무 활용 팁

현장에서도 그대로 씀

  • 포트폴리오 링크를 보낼 때는 배포 주소와 저장소 주소를 같이 보냄
  • 발표 피드백은 메모해 뒀다가 하나씩 처리함. 한꺼번에 시키면 무엇 때문에 바뀌었는지 모름
  • 작업물이 늘면 오래된 것부터 빼도 됨. 개수보다 카드마다 "내가 정한 것"이 보이는 쪽이 나음
  • 처음 보는 효과는 이런 효과에 맞는 라이브러리 후보 3개 알려줘로 이름부터 물어봄
  • 움직임은 레이아웃이 다 정해진 뒤에 넣음. 먼저 넣으면 모양을 고칠 때마다 다시 맞춰야 함

심화 · 지금은 몰라도 됨

  • 내 도메인 : GitHub Pages 설정의 Custom domain에서 내이름.com을 연결
  • 방문자 수 : 분석 도구가 필요하고 개인정보 안내도 같이 필요해서 오늘은 안 다룸
  • React Three Fiber : React에서 three.js를 쓸 때 같이 쓰는 연결용 라이브러리
  • SplitText : 글자를 한 글자씩 쪼개 움직이는 GSAP 플러그인. 지금은 무료
