3-1💬 에이전트Codex

Codex에게 리뷰 맡기기

  • 코드는 고치지 않음. 읽기만 함
  • 문제는 docs/REVIEW.md에 적음
  • 최대 5개, 중요한 것부터
  • 확실하지 않으면 "확인 필요"
Codex 입력창
무한 스크롤과 Supabase 불러오기 코드를
리뷰해줘. 코드는 고치지 말 것.

- 찾은 문제는 docs/REVIEW.md 에 적을 것. 최대 5개
- 문제마다 파일 이름, 무엇이 문제인지,
  사용자에게 어떻게 보이는지, 고치는 방법을 한 줄씩
- 중요한 것부터 순서대로
- 확실하지 않은 것은 "확인 필요"라고 표시할 것
화면에서 볼 것Codex가 쓴 docs/REVIEW.md의 항목들

도구 하나에서 AI만 바꾸기

STEP 5 · 도구 두 개 대신 대화를 이어 가며 모델만 바꿈

STEP 5🖱 직접

대화는 그대로, 모델만 바꿈

STEP 1~4는 도구 두 개를 켜고 파일로 일을 넘김

  1. omp(oh-my-pi)를 my-sns 폴더에서 켬
  2. GPT 모델로 요약을 받음
  3. /model로 Claude 모델로 바꿈
  4. 앞 대화를 이어서 답함

omp도 CLAUDE.md, AGENTS.md를 자동으로 읽음

omp
> 이 프로젝트 요약해줘
  (GPT 모델이 답함)

/model
  (Claude 모델로 바꿈)

> 방금 요약에서 빠진 것 있어?
  (앞 대화를 이어서 답함)
⚠️
기본값이 명령 실행까지 묻지 않고 하는 모드(yolo)임. 직접 써 보려면 먼저 --approval-mode write로 켬

출처: oh-my-pi GitHub (github.com/can1357/oh-my-pi)

6-1🖱 직접

Figma 연결

claude plugin install figma@claude-plugins-official
  1. Claude Code를 다시 켬

🔢
무료 계정 한도
View·Collab 좌석은 한 달에 20번, Dev·Full 좌석은 하루 200번까지 읽음. 프롬프트 한 번에 여러 번 쓸 수 있으니 같은 프롬프트를 반복하지 않음
여기까지 하면"Authentication successful. Connected to figma"가 보임

출처: Figma MCP Rate limits & access (developers.figma.com/docs/figma-mcp-server/rate-limits-access)

6-2🖱 직접

Figma에서 카드 고치기

1카드 프레임 열기Figma 파일의 게시물 카드
2한두 가지 바꾸기모서리 둥글기, 작성자 이름 굵기, 카드 사이 간격
3프레임 링크 복사오른쪽 클릭 → Copy/Paste as → Copy link to selection
🔗
Copy link to selection : 링크에 고른 프레임 번호가 들어감. 파일 전체를 읽으면 필요 없는 화면까지 읽어서 요청 횟수를 더 씀
