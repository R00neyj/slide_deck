# 교안·슬라이드 문체 검사

쓰기와 검사를 나눔. 내용 작업이 끝난 파일을 이 절차로 한 번 더 봄

기준은 프로젝트 `CLAUDE.md`의 `### 문체`, `### AI 티 나는 문체 피하기` 두 항목임. 이 스킬에 규칙을 따로 적지 않으니 시작할 때 그 두 항목을 다시 읽음

## 1. 검사 스크립트 실행

저장소 루트에서

```sh
python .claude/skills/lesson-style-check/scripts/check.py <교안.md> [slides/파일.html]
```

- 교안은 `rawdoc get <id> -o <스크래치>/<이름>.md` 로 받은 파일을 넣음
- 코드 블록, 인라인 코드, HTML 주석(강사용 메모), 링크 주소는 검사하지 않음. 학생이 복사하는 프롬프트는 고치지 않는 대상이라서임
- 결과는 규칙별 후보 목록과 줄 번호(`L12`). 걸렸다고 다 고치는 게 아님

## 2. 후보마다 판단

후보를 하나씩 보고 고칠지 정함. 판단 기준

| 규칙 | 고침 | 그대로 둠 |
|---|---|---|
| 부정 대구 | 앞을 부정하고 뒤를 긍정하는 수사 ("따라 하지 않고 화면을 봄") | 사실을 설명하는 부정 ("묻지 않고 실행하는 모드", "프레임이 아닌 파일 전체 링크를 줌"). 꼭 필요한 대비는 문서 전체에서 한 번만 |
| 음슴체 지시문 후보 | 학생에게 하라고 하는 말이 "봄", "하면 됨"으로 끝나 어색함 | 무엇이 일어나는지 설명하는 문장 |
| 상투구·과장·번역투·말 흐리기 | 대부분 고침 | 고유명사, 인용, 화면에 뜨는 문구 |
| 줄 끝 마침표 | 음슴체 줄 끝 마침표 | 한 줄 안에서 문장을 나누는 마침표 |
| 문단 몰림 (범용 동사, ~적 N, 매우·정말, 또한·따라서·즉, 대시, 당위 결말) | 한 문단에 몰려 있으면 일부만 바꿈 | 한 번씩 흩어져 있으면 둠 |

## 3. 스크립트가 못 잡는 것 직접 보기

문서를 처음부터 끝까지 한 번 읽으며 확인함

- 학생에게 하는 지시가 자연스러운지. 교안은 학생도 읽음
- 강사만 볼 내용이 본문에 섞여 있지 않은지 (있으면 `<!-- -->` 주석으로 옮김)
- 짧은 문장만 늘어놓지 않았는지. 이어지는 내용은 가끔 한 문장으로 이음
- 문단마다 요약 문장을 붙이지 않았는지
- 어려운 용어를 처음 나올 때 풀었는지
- 굵은 글씨가 꼭 필요한 곳에만 있는지 (스크립트가 개수만 알려 줌)

## 4. 고칠 때 지킬 것

- 문체만 고침. 수치·날짜·고유명사·명령어·파일 이름·사실 관계는 바꾸지 않음
- 코드 블록 안 프롬프트는 건드리지 않음
- 고치면서 새 상투구, 연결어미 뒤 쉼표, 다른 부정 대구를 만들지 않음
- 교안을 고치면 같은 문장이 있는 슬라이드도 같이 고침 (`CLAUDE.md` 슬라이드 규칙)

## 5. 다시 실행하고 보고

고친 파일로 스크립트를 다시 돌림. 후보가 줄었는지, 새로 생긴 후보가 없는지 봄

보고는 표 하나로 함

| 줄 | 규칙 | 원문 | 결과 | 이유 |
|---|---|---|---|---|

"그대로 둠"도 이유와 함께 적음. 교안은 그 뒤에 `rawdoc put --base-version <get 때 판 번호>`로 올림
